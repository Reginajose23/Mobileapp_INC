# Mobileapp_INC
I developed a web app to manage Indian church data and community interactions. I created input pages for church details and feedback collection. I built admin panel to upload images, videos, and daily messages.

In Home page, I added youtube video and verses,User can give feedback and send message.
I attached screenshot for reference.
I developed this mobile app using Ionic,php and MySQL.
